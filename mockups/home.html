The relay

Fund once. Release in order.

A pipeline is an ordered set of preassigned specialists, not a marketplace. The client defines the sequence; the contract enforces the handoff.

01

Fund

Lock the full budget

Every stage budget is escrowed up front in one Arc USDC transfer. Provider addresses, order, budgets, and deadlines become immutable.

02

Deliver

One active specialist

Only the current provider can submit a public HTTPS/IPFS deliverable. The client reviews it within the 24-hour evaluation window.

03

Relay

Approve and activate

Approval pays the current provider and activates the next preassigned specialist in the same transaction. Final approval completes the pipeline.

Built for inspection
